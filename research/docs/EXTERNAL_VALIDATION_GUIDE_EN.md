# Independent external validation of Lung-REA

## Online calculator and raw spirometry inputs

To support independent external validation of the finalized research model, we developed a publicly accessible English/Chinese calculator at https://shelly-linxu.github.io/Lung-REA/ . The source code is available at https://github.com/Shelly-linxu/Lung-REA . This manuscript documents application Lung-REA-web-1.1.0, verified source commit c73f591. The application version identifies the software interface; it does not denote a refitted prediction model. The frozen 29-predictor additive model remains C=0.003.

The default interface accepts measured pre-bronchodilator FEV1 and FVC in liters, baseline age in years, sex and measured height in centimeters. It derives race-neutral GLI Global z scores locally, using the same rspiro 0.5-compatible equations and age lookup behavior as the research pipeline. Users do not calculate z scores themselves. Advanced mode accepts existing GLI Global z scores. Percent predicted, the FEV1/FVC ratio and volumes in milliliters must not be entered in the liter fields. Software plausibility checks do not replace assessment of maneuver quality or study eligibility.

Peak expiratory flow accepts L/min or L/s; hemoglobin and albumin accept g/dL or g/L. The selected units are converted automatically before frozen scoring. Smoking categories and the other clinical, socioeconomic and laboratory inputs retain the definitions in e-Table 17. Optional unknown values use the frozen development imputation constants and are disclosed in the result. A cohort lacking entire required predictor panels cannot be treated as having ordinary sporadic missingness.

All calculations run in the browser on the user’s device. The interface does not upload entered measurements or use remote scoring. CSV and JSON downloads include entered measurements and units, engineered model inputs, actual scored values, imputation disclosures, five-year all-cause mortality risk, supported numerical age or an explicit range flag, and model/reference identifiers. Downloaded files contain health measurements and remain the user’s responsibility. Numerical age is not extrapolated outside the frozen same-sex reference support, which covers ages 50–79.

## Software agreement and frozen identity

Across all 9,548 retained study records, the JavaScript scoring engine agreed with the frozen Python scorer: maximum absolute risk difference 4.996×10⁻¹⁶ and maximum supported-age difference 1.492×10⁻¹³ years; age-support flags were identical. These are deterministic checks on existing study records, not another validation sample. Only aggregate audit results are distributed.

The JavaScript GLI conversion was compared with rspiro 0.5 on 500 artificial raw-spirometry cases, including age-boundary cases: maximum z-score difference 5.7554×10⁻¹³. Recomputed raw-volume z scores on all 9,548 retained records differed from their saved values by at most 3.5972×10⁻¹⁴. Eighty artificial cases independently tested the frozen risk engine against Python outputs. Browser checks covered raw-versus-z-score equivalence, unit conversion, bilingual value preservation, missingness disclosure, exports, invalid units, stale-result clearing and responsive layout. Synthetic fixtures contain no study participant records.

The model JSON SHA-256 is 964e27d44b28f5b54b4ecb7c3a72da0c8639c61c7ac759bf28353979aeb3d5ad; the original reference CSV SHA-256 is 9e28a3809823d4316abaf9d1ca18a970d6ba7495abef846e87879bd07bbc07dd. The online calculator and batch utility use these same frozen artifacts. GLI implementation attribution and GPL-2.0-or-later licensing are documented in the source repository. None of these software checks estimates transportability or clinical benefit.

## Independent external validation using the released model

The following recommendations are a prospective guide for independent investigators; no new external validation is reported in this update. Before outcome analysis, register the intended population, eligibility and measurement harmonization, endpoint, follow-up horizon, sample-size/precision justification, missingness policy, performance measures and subgroup analyses. Use an independent cohort with baseline spirometry, smoking and the required clinical and laboratory panel. Report recruitment setting, country, calendar period, predictor distributions, spirometry quality and selection/exclusions. Primary replication should respect ages 50–79 and the original measurement definitions; extensions should be labeled separately.

Archive the released software, model and reference identifiers before examining outcomes. Generate probabilities and age outputs without estimating new imputation constants, choosing new predictors, tuning parameters or rebuilding reference curves. The online calculator supports individual scoring and reproducible downloads; cohort-scale analysis should use the distributed batch scorer with the same engineered input definitions. Verify a small set of independently prepared records against the calculator before batch execution, and retain cohort records locally under the investigator’s governance arrangements.

The primary validation endpoint is five-year all-cause mortality. Assess AUROC, Brier score, calibration-in-the-large, calibration slope, observed-to-expected mortality and calibration plots by predicted-risk decile, with confidence intervals. Diagnostic calibration estimates must not be used to modify the primary predictions. Establish five-year status from death and follow-up times; do not classify participants censored before five years as survivors. If early censoring exists, prespecify suitable censoring-adjusted estimation, including its assumptions, rather than applying the original complete-horizon binary evaluation unchanged. Respect the cohort’s sampling design and report event counts and uncertainty.

Report prespecified sex, age, smoking and lung-function strata when adequately supported; retain all eligible participants for risk evaluation. For numerical Lung-REA, report supported-age coverage, below/above-reference flags and missingness separately. Respiratory and lung-cancer mortality can be secondary assessments when adequately adjudicated and sufficiently numerous, but the released score predicts all-cause risk and must not be represented as a cause-specific probability. Any model updating after direct validation requires a separately identified model and independent subsequent evaluation. External underprediction, overprediction or poor age coverage should be reported as observed.
